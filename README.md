# Portfolio Trần Minh Toàn

Website tĩnh bằng HTML, CSS và JavaScript. Không cần cài thư viện hoặc chạy build.

## Đưa lên GitHub Pages

1. Tạo repository public tên `TEN-GITHUB.github.io` (thay TEN-GITHUB bằng tên tài khoản GitHub).
2. Upload toàn bộ nội dung bên trong thư mục `dist` vào thư mục gốc repository. File `index.html` phải nằm ở gốc.
3. Vào Settings → Pages → Build and deployment → Deploy from a branch.
4. Chọn branch `main`, thư mục `/ (root)` và Save.
5. Sau khi GitHub triển khai thành công, mở URL GitHub Pages hiển thị trong Settings → Pages.

Có thể dùng repository với tên khác; các đường dẫn ảnh và tài nguyên đều là tương đối.

## Cập nhật

- Nội dung và thông tin liên hệ: `dist/index.html`.
- Màu sắc, kiểu chữ, bố cục và khung cắt avatar: `dist/style.css`.
- Hiệu ứng cuộn và xem ảnh lớn: `dist/script.js`.
- Hình ảnh và CV: `dist/assets/`.

Avatar giữ nguyên ảnh gốc; CSS cắt khung để tập trung vào chân dung. Ảnh trong thư viện có thể bấm để xem đầy đủ. Hiệu ứng tự giảm khi thiết bị bật Reduce Motion.

Font Be Vietnam Pro được tải từ Google Fonts; khi offline dùng Arial/sans-serif dự phòng.

Số liệu nghề nghiệp lấy từ CV do chủ portfolio cung cấp. Chưa có case study chi tiết cho từng dự án; có thể bổ sung khi có tài liệu.
